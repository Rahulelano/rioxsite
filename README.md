# RION TECHNOLOGIES (RIONXT) — Electronics Engineering & EMS

Official digital transformation and engineering portal for RION TECHNOLOGIES (RIONXT). Specializing in electronics R&D, PCB design and assembly, SMT/THT manufacturing, embedded systems, Industrial IoT (IIoT), and industrial automation.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
